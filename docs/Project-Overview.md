# Project Overview

## 1. Project Introduction

### Project Name

RAG 기반 챗봇 호텔 예약 서비스

### Description

AWS 인프라를 활용한 RAG 기반 챗봇 호텔 예약 서비스를 개발한다

### Background

RAG 기반 챗봇을 활용해 개발된 서비스의 범위를 벗어나지 않는 선에서 사용자의 질문에 맞는 정보와 선택지를 제공하는 호텔 예약 서비스를 개발하여 사용자의 편의성을 높이고자 한다
